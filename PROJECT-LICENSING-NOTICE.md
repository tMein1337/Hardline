## Why AGPL

Hardline builds directly on AGPL-covered Matrix components. Licensing this
project's own code under the same terms is the position that keeps the
combination distributable without further analysis.

## Source availability

The AGPL requires that anyone who receives a binary can obtain the exact
**Corresponding Source** for that binary. This project satisfies that by:

1. Tagging the exact commit each release is built from.
2. Publishing a source archive alongside every binary, for the same version.
3. Linking the source for that exact version next to the download and from
   inside the application, under **Settings → About**.

See [`RELEASING.md`](RELEASING.md) for the process, and
[`SOURCE.md`](SOURCE.md) for the file that ships in each release package.
